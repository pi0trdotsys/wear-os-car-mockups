# Car Silhouette Watch

Zaprojektuj i popraw UX/UI tej aplikacji na WearOS, mają tu być sylwetki najnowszych superaut oraz klasyków (ekran główny + AOD). Popraw tarczę by była astheatic future tech minilalism. Chcę by po prostu była ładna. Zaprojektuj makiety w TypeScript i napisz dokumentację dla Claude, który będzie implementował logikę tego projektu
